# Insurance Data Analytics Project

## About the Project
The Insurance Data Analytics project focuses on analyzing insurance data to understand customer details, insurance charges, and different patterns in the dataset.

The project includes data cleaning and Power BI visualizations to present meaningful insights.

## Dataset Information
- Original Dataset: insurance.csv
- Cleaned Dataset: insurance_cleaned.csv
- Total Records: Approximately 5,000
- Total Columns: 10

## Tools & Technologies
- Python (if actually used for cleaning)
- Microsoft Power BI
- CSV Dataset

## Project Workflow
1. Collecting the insurance dataset.
2. Understanding the dataset.
3. Cleaning and preprocessing the data.
4. Preparing the cleaned dataset.
5. Creating visualizations using Power BI.
6. Analyzing the results.

## Project Files
- `insurance.csv` – Original dataset.
- `insurance_cleaned.csv` – Cleaned dataset.
- `Dashboard/` – Power BI visualization screenshots.

## Key Objectives
- Understand insurance data.
- Improve data quality.
- Identify patterns and trends.
- Present insights through visualizations.

## Conclusion
This project helped explore insurance data, perform data cleaning, and create visual representations to understand the dataset better.
